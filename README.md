# Karthik G Bhat — Professional Portfolio

Version 3 is designed as a recruiter-focused, general software profile rather than a Java-only portfolio.

Included:
- Professional minimalist landing page
- No code/terminal hero card
- Broad software-development positioning
- Skills across Java, Python, JavaScript, React, databases, DevOps and AI/ML
- Two main projects only: Onboarding Wizard and Fraud Detection
- Research publication section
- Experience and education
- Hover and scroll reveal effects
- Responsive mobile navigation
- Resume CTA

Run:
npm install
npm run dev

Before publishing:
1. Replace `your-email@example.com`
2. Replace LinkedIn URL
3. Verify GitHub URL
4. Add `public/Karthik_G_Bhat_Resume.pdf`
5. Replace the publication Paper button `href="#"` with the real paper/PDF URL when available.
